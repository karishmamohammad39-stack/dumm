# Handoff Report: Iteration 6 - M1 Engine Core & I/O

## 1. Observation
- **Artifact Leak**: `src/core/io.py` (lines 36 and 75) uses `except Exception:`. This catches standard exceptions, but `KeyboardInterrupt` (a `BaseException`) bypasses the `except` block and thus leaves `tmp_path` files orphaned if a user cancels midway.
- **Format Inference Crash**: In `export_video` and `extract_audio` of `src/core/io.py`, `tmp_path` was being generated by unconditionally appending `.tmp` to the path (e.g., `f"{path}.{uuid.uuid4().hex}.tmp"`). MoviePy checks the end of the filename for extensions like `.mp4` or `.mp3` to determine codec/container. The `.tmp` suffix causes it to crash due to an unrecognized format.
- **Missing Error Tests**: `tests/core/test_io.py` lacks tests that cover `KeyboardInterrupt` or standard error masking cleanup. Additionally, the existing unit tests (`test_export_video`, `test_extract_audio_success`, etc.) hardcode `.tmp` at the very end of the string, which will break once the format inference is fixed.

## 2. Logic Chain
- Replacing `except Exception:` with `except BaseException:` handles `KeyboardInterrupt`, routing the control flow to properly `os.remove(tmp_path)` and prevent orphaned artifacts during user cancellation.
- Modifying `tmp_path` construction using `os.path.splitext` (e.g. `root, ext = os.path.splitext(path)` followed by `f"{root}.{uuid}.tmp{ext}"`) guarantees that the original extension is preserved at the very end, resolving the MoviePy inference crash.
- Existing tests that hardcoded `.tmp` needed to be updated to match the new string format (e.g., `out_path.1234.tmp.mp4`).
- We must add `test_export_video_keyboard_interrupt` and `test_extract_audio_base_exception` mock tests to guarantee that exceptions like `KeyboardInterrupt` correctly trigger the cleanup path and avoid regressions.

## 3. Caveats
- `os.path.splitext` is used for extension extraction. If a file doesn't have an extension, it resolves to an empty string, safely appending nothing, which is correct behavior.
